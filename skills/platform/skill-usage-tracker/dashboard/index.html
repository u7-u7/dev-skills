🍎🐧 macOS / Linux
make dashboard

🪟 Windows PowerShell
py .\skills\platform\skill-usage-tracker\scripts\dashboard_server.py --open
py .\skills\platform\skill-usage-tracker\scripts\dashboard_server.py --open --mock-count 500
