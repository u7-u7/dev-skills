# 文件交付

默认生成 `项目经历.md`，其中包含项目名称、项目简介、技术栈和 3–5 条项目亮点。技术栈后直接列出亮点，不添加“项目产出”等分组标题。

用户需要更完整的说明时，额外生成 `项目简介.md`，包括项目定位、服务场景、核心能力和技术要点。用户明确需要 CodeCV 时，额外生成 `CodeCV-项目经历.md`。

用户提供现有简历时，生成 `简历优化建议.md`（逐项目的问题、优化建议与改写示例）和 `优化后项目经历.md`（可直接替换进简历的项目经历）。

项目标题带定位说明时使用 `<项目名称>：<项目定位>`，只有项目名称时直接写名称。所有项目亮点使用 `* **小标题**：简介`，单行不超过 200 字；每条均包含动作、技术方案和贴合核心功能的产出。输出目录由用户指定；未指定时使用当前工作区的 `resume-deliverables/`。
