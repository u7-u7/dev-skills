# 任务清单模板

```markdown
# <需求名称> 任务清单

## 开发任务

### TASK-001：<动作与交付物>

- 状态：[ ]
- 应用 / 模块：<目标位置>
- 目标路径或符号：<已确认路径或调查产物>
- 追溯至：REQ-001、DES-001、PLAN-001
- 依赖：无 / TASK-xxx
- 可并行执行：无 / TASK-xxx
- 实施范围：
  - <明确的实现边界>
- 完成条件：
  - <可观察结果>
- 验证方式：
  - 命令或方法：`<命令或人工检查方式>`
  - 预期结果：<结果>
- 风险 / 备注：

## 覆盖矩阵

| REQ / NFR | DES | PLAN | TASK | 是否覆盖 |
|---|---|---|---|---|

## 最终验证

- [ ] 相关单元测试和集成测试通过。
- [ ] 适用的代码检查、类型检查或构建通过。
- [ ] 适用的兼容、迁移和回滚检查已完成。
- [ ] 每条范围内需求至少由一个任务覆盖。
```

质量门槛：

- 每个任务都有目标位置、依赖、完成条件和验证方式。
- 目标路径来自代码扫描；未知路径被拆成有明确产物的调查任务。
- 除非用户另行授权编码，否则任务清单在实现前停止。
