# 出图提示词模板

整理完文案后读取本文件。替换所有花括号字段并删除不适用段落，再交给图片生成工具；下面的比例和清晰度是视觉说明，不代表工具有对应 API 参数。

## 模板

```text
生成一张完整的中文手绘知识海报，主题是“{主题}”，面向{受众}，用于{用途}。输出一张真正的图片。

画布：{比例，默认横版16:9}，清晰、易读，纸面为干净白色，只有很轻的纸感。四周保留安全边距，所有字、图标和边框完整可见。

视觉语言：精致的 sketchnote / visual thinking / 手账涂鸦信息图。黑色马克笔描边，轻微自然手绘感；粗黑大标题，正文使用清楚易辨的中文。浅蓝、薄荷绿、浅黄、淡紫、浅粉的淡彩圆角分区，细彩色边线，分区标题配编号圆圈和笔刷底纹。黄色荧光笔只强调最重要的词。少量原创Q版讲解员与贴合主题的小图标、星光、对勾，人物外观保持一致，不遮挡文字。

参考图：{仅在实际传入图片时填写：图片1只参考白底、线条、色彩、字体层级和插画气质，不沿用其中的内容、账号、链接或署名。没有参考图时删除本段。}

布局：
- 顶部：{主标题位置、配套小插画、副标题荧光笔横条}。
- 中部：{逐区说明位置、大小、标题、正文形式、图标；核心区更大}。
- 关系：{明确箭头起终点、步骤顺序、分支条件或回路；没有流程时删除}。
- 底部：{行动区和一句话结论；用黄色强调结论中的核心短语}。
- 阅读顺序为{从左到右、从上到下，或用户指定顺序}；用位置与编号保持一致。

图中只允许出现以下文案，逐字准确绘制，不把字段说明或设计批注画出来，不自动加字：
主标题：“{准确标题}”
副标题：“{准确副标题}”
{模块1标题与逐条正文}
{模块2标题与逐条正文}
{按需继续模块}
一句话结论：“{准确结论}”

优先保证文字清楚、逻辑正确与分区易读。装饰服从内容，保持三档明确字号：主标题最大、分区标题次之、正文清晰。不要乱码、漏字、假文字、重复编号、装饰性乱箭头、文本交叠、裁切、无关英文、额外水印、照片、3D、深色背景、霓虹或厚重投影。
```

## 可复现示例：学习复盘

配套效果图见 [../assets/example.png](../assets/example.png)。以下是该图的生成提示词；示例内容只用于说明排版，不包含需要核验的统计或产品推荐。

```text
生成一张横版16:9中文手绘知识海报，主题“学习复盘：让知识真正留下来”。输出一张清晰完整的图片，白底，极轻纸感，安全边距。

风格：精致sketchnote手账涂鸦，黑色马克笔轮廓，自然手绘线条，粗黑手写大标题，正文中文清楚易读。浅蓝、薄荷绿、浅黄、淡紫、浅粉分区，细彩色圆角边框，分区标题有圆圈编号和彩色笔刷底纹。黄色荧光笔强调关键词。少量原创Q版学生：棕色短发、蓝色连帽衫，分别出现在左上思考区和右下行动区，外观一致；配书本、灯泡、对勾、星光小图标。插画不遮字。

布局：顶部15%为一行超大主标题和黄色荧光笔副标题条。中部60%为三栏：左侧浅蓝“① 为什么复盘”和浅粉“② 常见误区”上下叠放；中间薄荷绿“③ 四步复盘”是最大主区，内有四张步骤卡按2×2排列，左上回忆、右上解释、右下应用、左下回看，用箭头明确形成“回忆→解释→应用→回看→回忆”的顺时针闭环；右侧浅黄“④ 一页记录”和淡紫“⑤ 检查自己”上下叠放。底部25%为浅蓝“⑥ 现在就做”行动条，以及一句话结论，结论用黄色重点底纹。整体紧凑有序，文字保持足够大，阅读顺序清楚。

图中只出现下列文案，逐字准确绘制，不额外加说明：
主标题：“学习复盘：让知识真正留下来”
副标题：“少一点反复看，多一点主动想”
“① 为什么复盘”
“发现理解的空白”
“把知识连成线”
“让下一次行动更清楚”
“② 常见误区”
“看懂，不等于会用”
“抄完，不等于记住”
“收藏，不等于学会”
“③ 四步复盘”
“回忆”“合上资料，写出要点”
“解释”“用自己的话讲清楚”
“应用”“找一个小问题练习”
“回看”“记录卡点，再试一次”
“④ 一页记录”
“今天学了什么？”
“哪里还没弄懂？”
“下一步怎么练？”
“⑤ 检查自己”
“能讲清楚吗？”
“能举例子吗？”
“能独立做吗？”
“⑥ 现在就做”
“选一个知识点 → 写三条要点 → 做一次小练习”
一句话结论：“复盘不是再看一遍，而是让下一次做得更好。”

不要错别字、乱码、漏字、重复文案、错误箭头、文本重叠、额外署名、水印、写实照片、3D、深色背景或厚重阴影。内容准确与中文可读性优先于装饰。
```
