# Skill 使用看板淡彩色设计

## 目标

减少看板大面积纯白卡片带来的单调感，在不改变信息结构和数据功能的前提下，用低饱和淡彩色建立区域层级。

## 视觉方案

- 工具栏使用淡蓝到淡紫渐变，操作控件保留接近白色的清晰操作感。
- 四张指标卡分别使用淡蓝、薄荷绿、淡紫和蜜桃色，并使用对应深色显示核心数字。
- 真实数据状态使用薄荷绿，Mock 状态使用蜜桃到淡粉渐变，并继续显示明确的 Mock 文案。
- TOP 10 图表使用薄荷绿到淡蓝，全量表格使用淡蓝到淡紫，技能详情使用淡紫到淡粉。
- 快速开始区域使用奶油到淡粉，两端平台说明分别使用薄荷蓝和淡紫桃色。

## 交互与可访问性

- 正文与辅助文字保持深蓝灰，淡彩背景下满足可读性要求。
- 点击区域使用稳定的背景、左侧强调线和焦点环，不使用缩放动画。
- 排行条目与表格行支持键盘聚焦和 Enter/Space 查看详情。
- 文件导入入口支持键盘触发。
- 尊重 `prefers-reduced-motion`，移动端继续允许表格区域内部横向滚动。

## 验证

- 检查桌面首屏的淡彩层级和 Mock 状态。
- 检查 TOP 10 实际只渲染 10 条。
- 检查 375px 下不存在整页横向滚动。
- 运行 JavaScript 语法、服务测试和 diff 格式检查。
